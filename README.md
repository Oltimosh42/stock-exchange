## Порядок работы с Git Flow


Постоянные ветки:
- master - стабильные выпущенные версии.
- develop - объединение изменений для следующего выпуска.

Временные ветки:
- feature/<название> - новая функция. Создается от develop, после завершеия сливается в develop.
- release/<версия> - подготовка выпуска. Создается от develop, после завершеия сливается в master и develop.
Выпуск отмечается тегом.
- hotfix/<версия> - срочное исправление выпущенной версии. Создается от master, сливается в master и develop.
Исправленный выпуск отмечается тегом.

Коммиты изменений оформляются в стиле:
- feat(...): новая функция;
- fix(...): исправление;
- docs(...): документация;
- chore(...): служебное изменение.

Тестовые выпуски:
- v1.0.0 - первый выпск со списком инструментов;
- v1.0.1 - добавлена проверка пустого символа инструмента.
